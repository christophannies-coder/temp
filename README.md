# Transkript & Voiceover Studio mit KI-Sprachprüfung

Diese Quellversion enthält die fest integrierte Prüfung einer maschinellen
Übersetzung vor der Vertonung.

## Neuer Ablauf

```text
Video/Audio oder SRT
→ Transkription
→ Übersetzung
→ KI-Sprachprüfung mit Original-Kontext
→ Edge-TTS-Voiceover
→ optionale MKV-Ausgabe
```

Details, Einstellungen und Dateinamen stehen in
`KI_SPRACHPRUEFUNG_README.md`.

## Installation

```text
INSTALLIEREN.cmd
STARTEN_MIT_KONSOLE.cmd
```

Die virtuelle Umgebung `.venv` ist absichtlich nicht im Archiv enthalten und
wird vom Installationsskript lokal erstellt.
